For Salt users there’s an easier way to get everything installed using one simple command. Salt Formulas Formulas are pre-written Salt States, provided by the Salt community. There are plenty of formulas available unde the SaltStack Formulas GitHub organization. Their installation is easy, well explained in detail here: https://docs.saltstack.com/en/latest/topics/development/conventions/formulas.html.
